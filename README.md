# Vault

Personal cloud storage for Siahverse.

**Status: planned.** Vault is not currently a working app. The Siahverse homepage marks it as coming soon and disables its launch button. This repository reserves its home for development; application source has not been added yet.

## Scope

- Store and organize personal files.
- Build a clear, responsive web interface.
- Support Siahverse account integration and shared light/dark appearance.

These are intended features, not implemented functionality. Hosting, storage, and framework choices remain undecided.
